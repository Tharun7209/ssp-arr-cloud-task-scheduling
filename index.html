4. Tier-2 Local SSP-ARR Scheduler

Proposed Algorithm

Each VM independently governs its own local queue. Instead of static round robin slicing, SSP-ARR dynamically decides whether to execute reactively or predictively.

Mode = (CV_j ≤ 0.50) ? Reactive : Predictive
Inputs:
Head task from Q_j, sliding burst history of last W=5 completed cloudlets.
Outputs:
Optimal time slice quantum Q_j, updated task remaining burst.
Parameters:
History Window W = 5 | Bounds: Q_min = 0.001s, Q_max = 60.0s
Status:
Autonomous Per-VM Execution
